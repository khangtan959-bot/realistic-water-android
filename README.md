# Realistic Water for Android

This mod allows you to use sskaffy’s "Realistic Water" mod on your Android device.

## How to download and use

1. Download Fabric: https://docs.fabricmc.net/players/installing-fabric/
2. Download the original mod: https://github.com/sskaffy/Realistic-Water
3. Download this mod: https://github.com/khangtan959-bot/realistic-water-android
4. Place these mods into your `mods` folder.

**Note:** Your device must support Vulkan 1.2 to run this mod. For the best experience, Vulkan 1.3 is recommended.
